# Tennis Kata

Java kata for modeling tennis scoring rules.

## Purpose

This repository is a focused practice exercise for translating domain rules into clean code and tests.

## Contents

- Java implementation of tennis scoring behavior.
- Kata-style structure suitable for refactoring and test-driven practice.

## How To Use

Open the project in IntelliJ IDEA and run the available tests or main classes from the IDE.

## Status

Learning kata. The next upgrade is to add explicit scoring examples, edge cases, and a test coverage checklist.

## Validation

Use tests to cover ordinary scoring, deuce, advantage, and win conditions. Every new rule should have at least one named example.

## Engineering Notes

The kata is valuable when the tennis domain language stays visible in the code and tests. Avoid hiding rules behind generic conditionals.
